ARLinux KDE Plasma

This desktop uses KDE Plasma on Debian 13 ARM64.
The desktop and its dependencies are included in the distribution ZIP.
First start does not need an Internet connection.

Use the Plasma application menu for Dolphin (files), Konsole (terminal),
Kate (text editor) and installed Linux applications.
Double-tap the right-edge bar to open ARLinux Apps, Settings and Tasks.
Android provides the display, input method, audio, network and power controls.

OpenCode, Steam and Windows applications are installed on demand and require
downloads when first used. Your files live in the instance home directory.
